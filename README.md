# RUGS: Relightable Unity Gaussian Splatting

This project is based on [RUGS](https://github.com/ReV3nus/R).


## Steps

1. Download this repository.
2. Add the `projects/RUGS-BiRP` folder as a Unity project.

   * Recommended Unity Editor version: **2022.3.26f1**.
3. The project already contains example scenes and pre-processed 3D Gaussian Splats ready to interact with.
4. Import `.ply` files (GS-IR) via **Tools → Gaussian Splats → Create GaussianSplatAsset**.
5. 將Assets拖入GaussianSplats1與GaussianSplats2<img width="612" height="355" alt="image" src="https://github.com/user-attachments/assets/70943525-e49f-42ab-ada4-982e19114790" />


   * When importing `.ply` files into Unity, make sure to set **Quality** to **Very High**.
