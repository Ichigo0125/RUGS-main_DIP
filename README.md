# RUGS: Relightable Unity Gaussian Splatting

This project is based on [RUGS](https://github.com/ReV3nus/R).


## Steps

1. Download this repository.
2. Add the `projects/RUGS-BiRP` folder as a Unity project.

   * Recommended Unity Editor version: **2022.3.26f1**.
3. The project already contains example scenes and pre-processed 3D Gaussian Splats (3DGS) ready to interact with.
4. Optionally, you can import your own `.ply` files (GS-IR) via **Tools → Gaussian Splats → Create GaussianSplatAsset**.

   * When importing `.ply` files into Unity, make sure to set **Quality** to **Very High**.
